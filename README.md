# Yisheng Jiang

**GrepAwk** · Palo Alto, CA

Building browser-native and on-device tools for audio, video, and music. Focused on WebAssembly, Core ML, low-level DSP, and zero-copy pipelines.

## Focus Areas

- **Audio / DSP / MIDI** — Web Audio API, SoundFont engines, parametric EQ, FFT, wavetable synthesis, AudioWorklets
- **Video** — FFmpeg + WASM video editing; maintained multithreaded ffmpeg.wasm fork (FFmpeg 8.0.1 on Emscripten 4)
- **On-device iOS ML** — Core ML + AVFoundation for optical music recognition (OMR), polyphonic pitch detection → engraved sheet music, and camera settings optimization
- **Low-level systems** — C, Swift, Rust, WebAssembly, GPU/NN acceleration, lock-free designs
